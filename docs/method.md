# 方法說明

EmotionGain_RL 將中性英文句子改寫成指定情緒，同時盡量保留事件與邏輯內容。正式研究以「中性 → 喜悅」為主要任務。

## Prefix 訓練

Llama-3.2-3B 的底模參數保持凍結，每種情緒各有一組可訓練 Prefix。六種情緒、長度 20、隱藏維度 3072，共有 368,640 個可訓練數值，約為底模參數量的 0.012%。每筆訓練只更新目標情緒所對應的 Prefix。

## Threshold 與 reward

候選句需先通過格式、單句長度、照抄、語意相似度與雙向 NLI 矛盾等 Threshold 檢查。未通過者取得固定負 reward，不會因情緒分數高就抵銷失敗條件。

通過者的預設基礎獎勵為：

`R = 0.35e + 0.30s + 0.20f + 0.15c - P`

- `e`：經尺度換算及上下限處理的目標情緒增益。
- `s`：由句向量相似度與雙向 NLI 組成的語意保留分數，再換算到 reward 使用的尺度。
- `f`：以 GPT-2 交叉熵換算的流暢度特徵，結合改寫句本身的分數與相對原句的變化。
- `c`：依原句與改寫句長度計算的精簡度。
- `P`：過度照抄及雙向 NLI 分數不對稱的軟懲罰。

這是基礎公式，後續仍會限制情緒未提升或提升很小的 reward，並裁切到設定範圍。評分器用來提供訓練訊號，實際品質另以真人評估檢查。

## 最佳化流程

Warm-up 採 teacher forcing，只對目標改寫句與 EOS 計算交叉熵，Prefix 與原始提示的標籤設為 `-100`，不計入 loss。

RL 階段使用 REINFORCE，以 reward 與 EMA baseline 的差值計算 advantage。程式保留生成軌跡的 log probability，品質不合格但成功生成的軌跡仍以負 reward 參與更新。

逐 token 的 KL 項則比較目前策略與固定 Warm-up Prefix 的完整詞彙分布，約束訓練後的策略偏移。最後反向傳播並更新當次使用的 Prefix。
