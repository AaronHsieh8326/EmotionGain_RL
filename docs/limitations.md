# 研究限制

## Checkpoint 的選擇

研究在檢查訓練紀錄與生成句後，選擇 Step750 的 Prefix 進行正式比較。較後期的 checkpoint 雖可能取得更高自動分數，卻也出現情緒用詞堆疊、無依據的新內容或語意偏移等 reward hacking 現象。因此，Step750 是探索過程中選出的實務版本，不能認定相同步數適用於所有資料。

## 真人評估的範圍

研究以真人評估作為主要證據。38 位完成評估者是一般高二讀者，並非語言學專家，因此結果反映的是他們對短篇英文任務通知改寫的感受，不是專家語言品質評定。每個來源句只有 1–6 份評分；逐題平均與配對無母數檢定可減少部分評分差異的影響，但仍有不確定性。

## 結果不能延伸成全面優勢

經 Holm 多重比較校正，Prefix 的情緒評分顯著高於 Zero-shot，語意保留評分顯著高於 Few-shot，整體最佳選擇率也顯著高於兩種基準。其他維度比較沒有達到校正後的顯著門檻，不能據此宣稱所有面向都較好。

## 自動評分器的限制

評分器與真人評分的 Spearman 等級相關，以語意保留最高（0.67）；情緒增益的對齊程度有限（0.32），GPT-2 流暢度特徵與真人流暢度評分則未顯示有用的一致性（0.05）。評分器適合作為受條件約束的最佳化訊號，各維度仍需要進一步校準。
